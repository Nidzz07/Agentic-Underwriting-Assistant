## 0. Unit context

- **Story**: **US-UI-6** — the underwriter's **full decision-history / audit-trail view**: a paginated list of committed decisions (R6) and a strictly read-only per-decision detail (R7). The **6th/final frontend/React unit** and the **first UI unit to consume `decision_id` / `timestamp` / the full `AuditRecord` shape** — the read surface over the audit trail the two frozen write-path units (U7 `ui-approval-gate` / U8 `ui-override-form`) produce.
- **Dependencies**: `ui-shell` (frozen U10) — imports `AppFrame`/`Panel`, **`ReadOnlyRegion`** (`aria-readonly`), `RecommendationBadge`/`ConfidenceBadge`, `shell/copy` (`RECOMMENDATION_LABELS`/`CONFIDENCE_LABELS`/`COMMIT_ACTION_LABELS` + the **one `FORBIDDEN_TERMS`**), `RoleContext`/`useCurrentRole` (VIEWONLY-1 stub injection point). `ui-queue` (U5) + `ui-memo-view` (U6) + `ui-approval-gate` (U7) + `ui-override-form` (U8) — **all frozen**; their `fetchSeam`/`StructuralGuard`/by-construction/testid-lint are **mirrored as a convention, NOT imported** (incl. the **NEW `noOverrideFormImport`** alongside the existing sibling no-import guards). **WIRE-1 R6 + R7** consumed **by shape** (mocked in tests via the injected **dual-read** `historyFetchSeam`).
- **Interfaces/contracts (read-only, INV-FAITHFUL)**: reads R6 `GET /decisions?page=&size=` → a bounded page wrapper of `DecisionSummary` (carries the **human** `action` + `timestamp`, **not** the system recommendation — Q4-A of FD); reads R7 `GET /decisions/{decision_id}` → `AuditRecord` (the **only** source of the system recommendation, via `audit_tuple.rule_results`); error envelope `{error:{code,message,detail?}}` per WIRE-1 §4; R7 **404 `not_found`** surfaced through the **generic** `detailError` path. **No write body / no `submit*` / no non-GET builder anywhere** (FAITHFUL-1).
- **Database entities owned**: **none** — `ui-history` persists nothing; it is a **read consumer** of the audit trail (`audit-store`'s `AuditRecord`/`AuditTuple`/`CommittedDecision`, provisioned by `database` — the one real non-skip). Consumed **by shape**, never re-declared.
- **Boundaries**: **no `RoleGate`** (view-only for all authenticated roles — `can="read"` deliberately NOT used, which would exclude `admin`); the auditor read-only distinction is enforced **server-side** (`auth-rbac` SEC-4), not by this view; **no router** (master-detail navigation is internal `HistoryView` state); **no write/commit/edit/approve/override path** (those are U7/U8); **no LLM**; **no real network**; **no persistence**; **no superseded/version handling** (`status`/`supersedes_decision_id` display-only — NOSUPERSEDE-1).
