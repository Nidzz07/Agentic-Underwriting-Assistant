# Tech-Stack Decisions — `ui-override-form` (U8)

**Stage**: BUILD → NFR Requirements (per-unit) · **Unit**: U8 `ui-override-form` · **Date**: 2026-07-09
**Principle**: inherit the frozen `frontend/` substrate **unchanged**; add **only** the answer-driven decisions for this unit's override/reason write path + dual-operation reason-carrying seam. **No new dependency.**

---

| # | Decision | Rationale / source |
|---|---|---|
| **D1** | **Vitest + React Testing Library + jsdom** as the test substrate. | Inherited from ui-shell (U10), applied by ui-queue (U5) / ui-memo-view (U6) / ui-approval-gate (U7). No live backend; component + interaction assertions run in jsdom. **No new dependency.** |
| **D2** | **Plain JS/JSX — no TypeScript.** | FR-UI-5 (NFR-OVR-NOTS-1). Consistent with the whole `frontend/` package. |
| **D3** | **ESLint over the single `shell/copy` + `FORBIDDEN_TERMS` source**, registered on `src/overrideForm/**` via a config block **mirroring** the sibling blocks — **no `src/shell` edit, no second word-list**. | NFR-OVR-COPY-1 / ADVISORY-1 / TESTID-1. `LINT_FORBIDDEN_TERMS === FORBIDDEN_TERMS` asserted (single source). |
| **D4** | **`advisory-vocabulary` lint applied UNMODIFIED — copy verified clean NOW (Fold-3).** All 21 `OVERRIDE_COPY` strings were audited against the real `FORBIDDEN_TERMS.systemOutput` detector and trip **zero**; the human `override` is framed via "override"/"reason"/"record"/"committed" and never rendered as the system `DECLINE-RECOMMEND`. | NFR-OVR-ADVISORY-1 / NFR-OVR-Fold-3. **Unlike U7**, no copy correction was needed — the copy was clean as-drafted; no carve-out, no split list — cross-unit lint identity preserved. |
| **D5** | **Single injected/capturing double for BOTH operations — the dual-operation reason-carrying seam.** One object `{ fetchContext, submitOverride }`, each an **independently-counted spy** recording its own call log **and args** under the exact seam name (never a shared generic `calls` array); the `submitOverride` spy captures the `reason` argument for BODY-1 / REASONGATE-1. | §0 / NFR-OVR-Fold-A. **Mirrors** (does not import) U7's dual-double fold, extended to capture `reason`. **Non-vacuous cross-guard**: CONFIRM-1 asserts `submitOverride.calls.length === 0` **and** `fetchContext.calls.length === 1` at the pre-`Confirm` checkpoint (differing counts → a wrong-counter/swapped assertion fails). |
| **D6** | **Capability-free verification (Q2-A): structural import-scan + prop-contract RTL.** A StructuralGuard scan asserts `OverrideReasonInput` **and** `OverrideAffordance` import no seam module (`createOverrideFetch` / `overrideFetchSeam`) and reference no `submitOverride` (U7's invocation/import refinement, not bare-word); a prop-contract RTL asserts `OverrideReasonInput` renders from `{ value, onChange }` alone. | Q2-A / NFR-OVR-CAPFREE-1. The import scan proves structural absence of a commit path; the RTL proves the controlled-input contract. Extends U7's ND-Fold-3 for the NEW `OverrideReasonInput`. |
| **D7** | **StructuralGuard scans** (file/import walkers + detector self-tests) for `noBackendImport` / `noUiQueueImport` / `noMemoViewImport` / **`noApprovalGateImport`** (NEW) / `noRouterImport` and the `boundedFetch` scan. | NFR-OVR-REFNOTOWN-1 / PERF-1. Mirrors the sibling `boundedFetch`/`no*Import` pattern **without importing** it; `noApprovalGateImport` is new because U8 is the first sibling that must also not import the frozen U7. |
| **D8** | **RoleGate render coverage via a stub `RoleProvider` over all three roles + null (inherited U7 Q3-A).** `underwriter` → override affordance present; `auditor`/`admin`/`null` → absent. | NFR-OVR-RBAC-1. `RoleProvider`/`useCurrentRole` is ui-shell's frozen seam (reused, not modified). Pins both non-underwriter `act:false` cells + the unauthenticated case. |
| **D9** | **Mandatory-reason gate — whitespace fixture set + send-as-entered payload + divergence doc (Q3-A).** Blank set `{ "", " ", "\t", "\n", " \t\n " }` → zero POSTs; a non-blank control → exactly one POST carrying the reason **verbatim** (guard `trim()`s only the enable/disable decision, never the sent value); a documentation test asserts the guard is `trim()`-based and **not** byte-identical to `str.strip()`. | Q3-A / NFR-OVR-REASONGATE-1 / NFR-OVR-Fold-1. The exotic full-Unicode matrix is rejected (over-build against the non-authoritative design); the divergence resolves via the 409 tail. |
| **D10** | **Reason preservation + echo — two distinct assertions (Q4-A).** (1) preservation teeth (reason survives Cancel + errorCommit unchanged); (2) a dedicated read-only echo DOM assertion (`override-confirm-reason-echo`), distinct from the post-submission `override-committed-reason`. | Q4-A / NFR-OVR-REASONKEEP-1 / NFR-OVR-Fold-2. Separate assertions keep a preservation regression and an echo regression diagnosable; the two nodes are distinct states/sources. |
| **D11** | **ONE consolidated transition test** on the same dual-operation double, covering all state-machine legs **including both split-error recovery paths** (`errorRead --Retry--> loading`, `errorCommit --> ready`) **and the reason-carrying states** (reason preserved across Cancel/errorCommit). | NFR-OVR-FETCH-1. Mirrors U7's consolidated transition test, extended for the reason path. |
| **D12** | **`data-testid` convention `override-<element>-<purpose>`** enforced by an `override-testid-convention` lint/test (+ detector self-test), mirroring the sibling testid-convention. | NFR-OVR-TESTID-1. Namespaced to `override-*` so tests target this unit unambiguously. |
| **D13** | **PERF-1 / A11Y-1 observed/soft.** Confirm-dialog focus-trap + Escape-to-cancel and the reason `<textarea>` label association are **recorded NFR-Design targets**, not Phase-1 gates. | NFR-OVR-PERF-1 / A11Y-1. The **BR-OVR-3 "cancelable" (CANCEL-1)** and **BR-OVR-8 "blank blocks submit" (REASONGATE-1)** invariants stay gated as full-rigor teeth — only the a11y polish is soft, consistent with the sibling precedent. |
| **D14** | **Frontend tests fold into the existing Vitest run** (separate runner from the backend pytest tree); no change to the backend suite. QA-6 ≥90% coverage on `frontend/src/overrideForm` at Code-Gen. | Consistent with ui-shell/ui-queue/ui-memo-view/ui-approval-gate — the Vitest suite grows; the backend pytest total is untouched (separate runner/tree). |

**No new dependency** is introduced: Vitest + RTL + jsdom + ESLint + the ui-shell mechanisms already exist in `frontend/`. This unit adds source + tests only.
